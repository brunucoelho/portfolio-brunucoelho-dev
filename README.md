## Observações

- O arquivo original não estava em React; ele já era um HTML estático com CSS embutido.
- A nova versão mantém o layout e o conteúdo, mas separa a estilização em arquivos CSS por seção.
- O JavaScript foi adicionado apenas para melhorar a coesão das interações, especialmente filtro de projetos e navegação ativa.
- Para abrir localmente, basta executar o arquivo `index.html` no navegador.
